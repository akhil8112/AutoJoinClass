# AutoJoinClass

## Overview
AutoJoinClass is a web automation tool that automatically joins online classes or meetings at the scheduled time. This project helps students avoid missing classes due to late login, network delay, or manual joining.

The system allows users to store class links and schedules, and the application automatically opens and joins the class at the correct time.

The project is deployed online using Vercel for fast and reliable hosting.

---

## Features
- Automatically joins online classes
- Schedule class timing
- Store class links
- Simple and user-friendly interface
- Saves time and avoids missing classes
- Web-based application
- Deployed online

---

## Tech Stack
- HTML
- CSS
- JavaScript
- Node.js
- Vercel (Deployment)

---

## How It Works
1. User enters class link and time
2. System stores the schedule
3. When time matches, the system automatically opens the class link
4. User joins the class automatically

## Installation (Run Locally)

### Step 1: Clone Repository
```
git clone https://github.com/akhil8112/AutoJoinClass.git
cd AutoJoinClass
```

### Step 2: Install Dependencies
```
npm install
```

### Step 3: Run the Project
```
npm start
```

### Step 4: Open in Browser
```
http://localhost:3000
```
